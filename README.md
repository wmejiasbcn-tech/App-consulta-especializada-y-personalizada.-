# App-consulta-especializada-y-personalizada.-
És una app especialitzada y personalizada sobre salud sexual, prácticas de riesgo para VIH/ITS, anàlisis situacional individualizado y con recomendaciones de gestión del placer y de la salud sexual. Además incluye información, orientación para la reducción de riesgos y daños en la practica del chemsex, siempre adaptado a las necesidades del usuario
